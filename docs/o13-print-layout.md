# O-13 睡眠レポート印刷レイアウト 実装計画

## 状態

**IMPLEMENTED — 自動検証済み（実印刷は未検証）**

## 1. 目的

Sleep Compass の「時間」タブと「分割」タブについて、現在選択されている月と表示データを、印刷またはPDF保存に適した専用レイアウトで確認できるようにする。

この機能は睡眠の傾向をセルフモニタリングするためのレポートであり、医学的な診断、原因の断定、睡眠の良否の保証を行うものではない。

## 2. 背景と位置付け

O-12 はローカルファースト運用、クラウド依存の解消、データ保全を対象とした移行フェーズである。印刷レイアウトはその対象外であるため、ユーザー向けWeb機能の改善として O-13 に分離する。

O-12j の旧Maya環境およびBilling整理は別管理であり、O-13 の開始条件・完了条件には含めない。

## 3. 対象範囲

### 対象画面

- 「時間」タブ
- 「分割」タブ

### 共通機能

- 各タブに「印刷用レイアウトを表示」操作を提供する。
- 同一画面内で印刷プレビューを表示する。別ウィンドウや外部サービスは使用しない。
- 印刷プレビューで「コンパクト版」と「完全版」を切り替えられる。
- 「印刷する」操作でブラウザ標準の印刷ダイアログを開く。
- 「戻る」操作で元のタブ・月選択・統合表示状態に戻る。
- プレビューと印刷結果は、現在選択中の月、統合後／統合前の表示種別、睡眠日区切り時刻を反映する。
- 印刷プレビューを開いた直後は、起動元のタブを対象とし、`コンパクト版` を初期選択する。
- プレビュー中にレポート種別（時間／分割）は変更しない。別の種別を出力する場合は、元のタブへ戻ってから開く。
- 睡眠日の表示順は、起動元の画面と同じ新しい日付順とする。

### 印刷ヘッダー

各レポートの先頭に次を表示する。

- Sleep Compass
- レポート種別: `睡眠の記録（時間）` または `睡眠の記録（分割）`
- 対象月
- 表示データ種別: `統合後` または `統合前`
- 睡眠日区切り時刻
- 出力日時
- `非診断・セルフモニタリング用` の注記

## 4. レイアウト仕様

### 4.1 コンパクト版

月内の睡眠日を一覧で確認するための形式とする。

各睡眠日の表示内容:

- 睡眠日
- 総睡眠時間
- 睡眠回数
- 主睡眠候補
- 24時間タイムライン
- 主睡眠、仮眠、夕方睡眠の凡例
- 分割タブでは、仮眠・夕方睡眠の有無と分割睡眠スコア

ステージ情報がある場合、24時間タイムラインの睡眠ブロック内に REM／コア／深い睡眠／睡眠の区分を表示する。コンパクト版ではステージ時間の詳細表は表示しない。

### 4.2 完全版

日ごとの内容を詳しく確認・保存するための形式とする。コンパクト版の内容に加えて、次を表示する。

#### 時間タブ

- 睡眠ブロックの詳細表
  - 開始・終了時刻
  - 睡眠時間
  - 分類（主睡眠候補、仮眠候補、夕方睡眠、その他）
  - ステージ内訳
- ステージがある日の REM／コア／深い睡眠の時間内訳

#### 分割タブ

- 主睡眠候補と追加睡眠の関係図
- 分割睡眠スコアとその理由
- 睡眠ブロックの詳細表
  - 開始・終了時刻
  - 睡眠時間
  - 分類
  - ステージ内訳

### 4.3 睡眠ステージの表示

- REM、コア、深い睡眠、通常睡眠は、既存の `stageSegments` を使用して表示する。
- 完全版の表では、例として `コア 4時間10分 / REM 1時間20分 / 深い睡眠 55分` のように集計して表示する。
- ステージがないデータについては推測や補完をせず、`ステージ未取得` と表示する。
- 色だけに意味を依存しない。タイムライン、凡例、表のラベルで区別できるようにする。

## 5. 印刷品質・プライバシー要件

- 基本用紙は A4縦とする。
- 1ページに収まる日別カード、関係図、ブロック詳細表は途中で改ページしない。
- 1日の完全版が1ページに収まらない場合は、内容を縮小して押し込めない。詳細表の見出しを繰り返し、読みやすい位置で制御して改ページする。
- 背景色が印刷されない設定やモノクロ印刷でも、分類とステージを識別できるようにする。
- 画面タブ、月選択、表示種別切替、プレビュー操作ボタン、装飾画像は印刷対象外とする。
- 生データのファイル名、同期フォルダのパス、端末名、API状態、認証情報は印刷しない。
- 印刷対象データを外部サービスへ送信・保存しない。利用者がブラウザの印刷先として紙またはPDF保存先を選択する。
- ブラウザ固有のURL・ページ番号などのヘッダー／フッターはWebアプリ側で強制的に制御しない。必要に応じて利用者が印刷設定で無効化する。

## 6. 実装方針

### 状態と画面遷移

`App.tsx` に、印刷プレビューの対象タブ、出力形式、出力日時を保持する状態を追加する。

通常画面の月選択と統合後／統合前の表示状態は変更せず、印刷プレビューには同じ集計済みの月別サマリーを渡す。

### コンポーネント

印刷専用の表示は、通常画面の折りたたみ詳細の開閉状態に依存させない。次のように専用コンポーネントへ分離する。

- `PrintLayoutPreview`: プレビュー画面と操作
- `PrintReportHeader`: 共通ヘッダー
- `TimelinePrintReport`: 時間タブのコンパクト版／完全版
- `FragmentationPrintReport`: 分割タブのコンパクト版／完全版
- `PrintTimelineBar`: 印刷用24時間タイムライン
- `SleepBlockPrintTable`: 完全版のブロック・ステージ詳細表

コンポーネントの最終的な配置は、既存の `src/components` の責務と重複しない範囲で実装時に確定する。

### CSS

`src/App.css` に画面プレビュー用のスタイルと `@media print` を追加する。

- `@page` でA4縦と余白を定義する。
- `break-inside: avoid` 等を使い、日別単位の分割を防ぐ。
- 印刷時はプレビュー本文だけを表示する。
- 影、固定ナビゲーション、背景装飾を除去する。
- `print-color-adjust: exact` を補助的に指定するが、背景色が無効でも情報が失われない設計とする。

### データ整形

既存の `SleepDaySummary`、`ClassifiedSleepBlock`、`SleepStageSegment` を使用する。印刷専用の集計は表示用途に限定し、Processor、Processed Data Contract、同期処理、分析ルールを変更しない。

現在 `App.tsx` にあるタイムライン位置計算、ステージ表示名、ステージ時間集計などの表示用処理は、印刷コンポーネントへ複製しない。通常画面と印刷画面の双方から使える純粋関数として `src/lib/print/sleepPrint.ts`（または同等の表示用ユーティリティ）へ抽出する。抽出後も、選択済みの統合後／統合前 `SleepDaySummary[]` だけを入力とし、印刷用の再分析は行わない。

## 9. 受け入れ条件

1. 「時間」「分割」タブのどちらからも印刷プレビューを開ける。
2. 各タブでコンパクト版・完全版を切り替えられる。
3. 選択中の月と統合後／統合前の状態が、印刷プレビューに正しく反映される。
4. 完全版は睡眠ブロックの詳細と、利用可能なステージ内訳を表示する。
5. ステージがない場合、推測せず `ステージ未取得` と表示する。
6. データがない月は、対象月と空状態の説明だけを表示する。
7. 印刷時に操作UI・ナビゲーション・同期情報・ローカルパスが含まれない。
8. A4縦のプレビューおよびPDF保存で、日別カードや表が途中で不自然に切れない。
9. 色を印刷しない設定でも、睡眠分類・ステージを文字と罫線で判別できる。
10. 通常の「時間」「分割」タブ、データ取り込み、分析、ローカルAPIの既存動作に回帰を起こさない。
